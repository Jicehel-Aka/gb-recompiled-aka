Game Boy (gb-recompiled) - version PC

Lancer :   gb_recompiled_pc            ouvre le lanceur sur le dossier "roms" a cote du programme
           gb_recompiled_pc  dossier    ouvre le lanceur sur ce dossier
           gb_recompiled_pc  ma_rom.gb  lance directement la ROM (Windows : glisse la ROM sur le .exe)
Linux :    installe SDL2 (Debian/Ubuntu : sudo apt install libsdl2-2.0-0)

Lanceur (sous-dossiers acceptes)
  Haut / Bas, molette   choisir              Page precedente / suivante   defiler
  Entree, X, Espace     jouer / ouvrir       Retour arriere, Z, Gauche    dossier parent
  Echap                 quitter

En jeu
  Croix          Fleches ou W A S D
  A / B          X ou Espace / Z ou B
  Start / Select Entree / Retour arriere ou Maj droite
  Plein ecran    F11
  Echap          retour au lanceur (ferme la fenetre pour quitter)

Options : --scale N (taille de la fenetre, defaut 4)
Sauvegardes : dossier utilisateur SDL (gb-recompiled/aka), un .sav par nom de ROM.
Les ROM ne sont pas fournies. Runtime : MIT (c) arcanite24, voir LICENSE-gb-recompiled.txt.
